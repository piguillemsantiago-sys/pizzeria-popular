# Pizzería Popular - Web

Sitio web oficial de Pizzería Popular, cadena de restaurantes argentinos en España.

## Instalación

```bash
npm install
```

## Configuración

Crear archivo `.env`:

```
PORT=3000
NODE_ENV=production
```

## Desarrollo

```bash
npm run dev
```

## Producción

```bash
npm start
```

## Deploy en Railway

```bash
railway up
```
